# Flashcard App

A simple and interactive **Flashcard App** built using **HTML, CSS, and JavaScript** to make learning and revision easier.

## About the Project

The Flashcard App is a web-based learning tool that helps users revise and memorize concepts using digital flashcards. Each flashcard contains a **question on the front** and an **answer on the back**.

Users can flip cards, navigate through the flashcards, shuffle them, and keep track of how well they remember the answers.

The project focuses on providing a **simple, interactive, and user-friendly learning experience** using basic web technologies.

## Features

* Interactive flashcards
* Click to flip between question and answer
* Previous and Next navigation
* Shuffle flashcards
* Track current card and total cards
* Mark answers as "Knew It"
* Mark answers as "Didn't Know"
* Calculate learning score
* Organize cards by categories
* Responsive and user-friendly design

## Tech Stack

* **HTML5** – Creates the structure of the application
* **CSS3** – Handles styling, layout, animations, and responsiveness
* **JavaScript** – Handles flashcard logic, navigation, interactions, and scoring

## How to Run

1. Clone the repository:

```bash
git clone <repository-url>
```

2. Open the project folder.

3. Open `index.html` in any modern web browser.

No server or additional installation is required.

## How to Use

1. Open the Flashcard App.
2. Read the question displayed on the flashcard.
3. Click the card to reveal the answer.
4. Select:

   * **Knew It** if you remembered the answer.
   * **Didn't Know** if you did not.
5. Use **Next** and **Previous** to navigate through the cards.
6. Use **Shuffle** to randomize the flashcards.
7. View your final score after completing the deck.
